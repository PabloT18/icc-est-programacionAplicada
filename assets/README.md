# Assets del proyecto

- `logos/`: originales entregados por el docente, sin redibujar ni cambiar proporciones.
- `fonts/`: DejaVu Sans normal y negrita, misma familia en web y diapositivas.
- Cada contenido tiene `assets/guia-visual.svg` con texto verificable y algunos incluyen una analogía generada.
- Las imágenes de analogía no sustituyen especificaciones técnicas ni esquemas eléctricos.
- `catalogo.json` contiene navegación y datos de autoría para regenerar el sitio.

El texto Markdown adopta la fuente del visor que lo abra. La versión HTML y las presentaciones utilizan DejaVu Sans; GitHub controla la tipografía de su propio visor.
